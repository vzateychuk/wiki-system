# Wiki System OCR

Монорепозиторий вики-системы, позволяющий пользователям загружать скриншоты и автоматически извлекать из них текст с помощью OCR.

## 🏗 Структура проекта

Проект организован как монорепозиторий с использованием [npm workspaces](https://docs.npmjs.com/cli/v7/using-npm/workspaces):

- `apps/back` — Бэкенд-сервис, отвечающий за обработку изображений и распознавание текста.
- `apps/front` — Клиентское приложение для загрузки изображений и просмотра результатов.
- `uploads/screenshots` — Локальное хранилище для загруженных скриншотов (настраивается через переменную `UPLOAD_DIR`).

## 🛠 Технологический стек

### Frontend
- **React**
- **TypeScript**
- **Vite**

### Backend
- **Node.js v22**
- **Express**
- **TypeScript** (запуск через `tsx`)
- **Tesseract OCR** (`node-tesseract-ocr`)

## 🚀 Быстрый старт

### Предварительные требования
- Node.js v22+
- Установленный в системе Tesseract OCR.

### Установка зависимостей
```bash
npm install
```

### Запуск в режиме разработки

Запуск сервисов осуществляется из корня монорепозитория:

**Запуск бэкенда:**
```bash
npm run dev:backend
```

**Запуск фронтенда:**
```bash
npm run dev:front
```

## ⚙️ Конфигурация

Бэкенд использует переменные окружения для настройки. Основная переменная:

- `UPLOAD_DIR`: Путь к директории, в которой будут храниться скриншоты. (По умолчанию: `uploads/screenshots`)
